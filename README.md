# Unako Fanana - Developer Portfolio

A responsive 5-section web portfolio showcasing projects, technical skills, and background in software development.

## Tech Stack
- HTML5, CSS3, JavaScript
- Hosted on GitHub Pages / Netlify

## Sections Included
- **Hero:** Profile overview and quick links
- **About:** Professional background
- **Skills:** Technology stack & tools
- **Projects:** Case studies (Problem, Approach, Outcome, Tech Used)
- **Contact:** Email and profile links

## Setup & Local Development
1. Clone the repository: `git clone https://github.com/unakofanana/unako-fanana-portfolio.git`
2. Open `index.html` in your browser or run via Live Server.
